# Helder A. S. Costa — Academic Portfolio

A simple, responsive academic portfolio inspired by the structure of the
[Maria Brió Portfolio](https://github.com/JuditKaramazov/MariaBrioPortfolio).

## Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- No framework or build step

## Sections

- About
- Research
- Academic Experience
- Research Toolkit
- Selected Publications
- Supervision & Students
- Contact
- Light/dark theme switcher

## Run locally

Open `index.html` in a browser, or use a local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy to GitHub Pages

1. Create a new GitHub repository.
2. Upload all files in this folder.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch** and choose `main` / root.
5. Save.

## Source information

The academic content was adapted from the public Lattes CV supplied for this portfolio.
The portfolio layout is independently implemented in HTML/CSS/JavaScript.
